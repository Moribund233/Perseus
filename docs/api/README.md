# Perseus API 功能点文档

> **项目**: Perseus — Git 代码托管平台
> **更新日期**: 2026-07-24

---

## 已实现功能点

### 1. 用户系统

| 功能 | 状态 | 说明 |
|------|------|------|
| 用户注册 | ✅ | 支持用户名、邮箱、密码注册 |
| 用户登录 | ✅ | JWT 双 Token（access + refresh）认证 |
| Token 刷新 | ✅ | 使用 refresh_token 换取新令牌对 |
| 用户信息查询 | ✅ | 获取当前用户 / 指定用户信息 |
| 用户信息更新 | ✅ | 普通用户自更新 + 管理员全局更新 |
| 用户删除 | ✅ | 管理员权限，级联清理关联数据 |
| Token 签发/验证/撤销 | ✅ | JWT HS256，可配置过期时间 |
| 密码哈希存储 | ✅ | 使用安全哈希算法 |
| 密码修改 | ✅ | 当前用户通过旧密码验证后修改 |
| 用户头像 | ✅ | 上传 / 获取用户头像（JPEG/PNG/GIF/WebP） |
| 用户 Dashboard | ✅ | 聚合可访问仓库数、待处理 PR/Issue、最近动态 |
| 跨仓库 PR 列表 | ✅ | 当前用户参与/创建的 PR 聚合查询 |
| 跨仓库 Issue 列表 | ✅ | 当前用户创建/被指派的 Issue 聚合查询 |

| 解绑 OAuth 账号 | ✅ | 解除指定 provider 的绑定 |
