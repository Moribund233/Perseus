# Perseus API 功能点文档

> **项目**: Perseus — Git 代码托管平台
> **更新日期**: 2026-06-13

---

## 已实现功能点

### 1. 用户系统

| 功能 | 状态 | 说明 |
|------|------|------|
| 用户注册 | ✅ | 支持用户名、邮箱、密码注册 |
| 用户登录 | ✅ | JWT 双 Token（access + refresh）认证 |
| Token 刷新 | ✅ | 使用 refresh_token 换取新令牌对 |
| 用户信息查询 | ✅ | 获取当前用户 / 指定用户信息 |
| 用户信息更新 | ✅ | 普通用户自更新 + 管理员全局更新 |
| 用户删除 | ✅ | 管理员权限，级联清理关联数据 |
| Token 签发/验证/撤销 | ✅ | JWT HS256，可配置过期时间 |
| 密码哈希存储 | ✅ | 使用安全哈希算法 |

### 2. 仓库管理

| 功能 | 状态 | 说明 |
|------|------|------|
| 仓库 CRUD | ✅ | 创建、查询、更新、删除 |
| 公开/私有可见性 | ✅ | is_public 字段控制 |
| 物理仓库初始化 | ✅ | 创建时初始化 bare Git 仓库 |
| 搜索/分页 | ✅ | 基础搜索 + 分页查询 |
| 仓库统计 | ✅ | Fork 计数等 |

### 3. Fork 机制

| 功能 | 状态 | 说明 |
|------|------|------|
| Fork 创建 | ✅ | `git clone --bare` 物理复制 |
| 用户 Fork 列表 | ✅ | 分页查询用户的所有 Fork |
| 仓库 Fork 列表 | ✅ | 分页查询仓库的所有 Fork |
| Fork 源追溯 | ✅ | 从 Fork 定位源仓库 |
| Fork 同步 | ✅ | `git fetch origin` 同步上游变更 |
| 防重复 Fork | ✅ | 同一用户不可重复 Fork 同一仓库 |

### 4. 分支管理

| 功能 | 状态 | 说明 |
|------|------|------|
| 分支 CRUD | ✅ | 创建、查询、更新、删除 |
| 默认分支设定 | ✅ | GET 默认分支 + PUT 设置默认分支 |
| 分支保护 | ✅ | 保护/取消保护、保护状态检查 |
| 分支保护设置 | ✅ | 自定义保护规则（Code Review、状态检查）|

### 5. 提交管理

| 功能 | 状态 | 说明 |
|------|------|------|
| 提交列表查询 | ✅ | 分页 + 偏移量，可按分支筛选 |
| 提交详情查询 | ✅ | 单次 commit 的详细信息 |
| 提交历史树 | ✅ | 跨分支提交历史树 |
| 提交搜索 | ✅ | 按关键词搜索提交 |
| 按作者查询 | ✅ | 按作者邮箱过滤提交 |
| 最新提交查询 | ✅ | 仓库级/分支级最新提交 |
| 提交计数 | ✅ | 仓库级 + 分支级提交数量统计 |
| 分支提交列表 | ✅ | 指定分支的提交列表 + 计数 |
| Diff 查看 | ✅ | 两分支/提交之间的差异对比 |

### 6. Pull Request
