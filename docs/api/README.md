# Perseus API 功能点文档

> **项目**: Perseus — Git 代码托管平台
> **更新日期**: 2026-06-10

---

## 已实现功能点

### 1. 用户系统

| 功能 | 状态 | 说明 |
|------|------|------|
| 用户注册 | ✅ | 支持用户名、邮箱、密码注册 |
| 用户登录 | ✅ | JWT 双 Token（access + refresh）认证 |
| 用户信息查询 | ✅ | 获取当前用户 / 指定用户信息 |
| 用户信息更新 | ✅ | 普通用户自更新 + 管理员全局更新 |
| 用户删除 | ✅ | 管理员权限，级联清理关联数据 |
| Token 签发/验证/撤销 | ✅ | JWT HS256，可配置过期时间 |
| 密码哈希存储 | ✅ | 使用安全哈希算法 |

### 2. 仓库管理

| 功能 | 状态 | 说明 |
|------|------|------|
| 仓库 CRUD | ✅ | 创建、查询、更新、删除 |
| 公开/私有可见性 | ✅ | is_public 字段控制 |
| 物理仓库初始化 | ✅ | 创建时初始化 bare Git 仓库 |
| 搜索/分页 | ✅ | 基础搜索 + 分页查询 |
| 仓库统计 | ✅ | Fork 计数等 |

### 3. Fork 机制

| 功能 | 状态 | 说明 |
|------|------|------|
| Fork 创建 | ✅ | `git clone --bare` 物理复制 |
| 用户 Fork 列表 | ✅ | 分页查询用户的所有 Fork |
| 仓库 Fork 列表 | ✅ | 分页查询仓库的所有 Fork |
| Fork 源追溯 | ✅ | 从 Fork 定位源仓库 |
| Fork 同步 | ✅ | `git fetch origin` 同步上游变更 |
| 防重复 Fork | ✅ | 同一用户不可重复 Fork 同一仓库 |

### 4. 分支管理

| 功能 | 状态 | 说明 |
|------|------|------|
| 分支 CRUD | ✅ | 创建、查询、删除 |
| 默认分支设定 | ✅ | `default_branch` 字段 |
| 分支保护 | ✅ | 保护分支不可删除，可要求 Code Review |

### 5. 提交管理

| 功能 | 状态 | 说明 |
|------|------|------|
| 提交历史查询 | ✅ | 分页查询某分支的 commit 历史 |
| 提交详情查询 | ✅ | 单次 commit 的详细信息 |
| Diff 查看 | ✅ | 两分支/提交之间的差异对比 |

### 6. Pull Request

| 功能 | 状态 | 说明 |
|------|------|------|
| PR CRUD | ✅ | 创建、查询、更新、关闭、重开 |
| PR 合并 | ✅ | 合并到目标分支 |
| PR 评论 | ✅ | 行内评论 + 全局评论 |
| PR Code Review | ✅ | 审查状态（approve/request changes/comment） |
| Diff 对比 | ✅ | PR 源/目标分支差异 |
| 冲突检测（基础） | ✅ | 检查是否存在合并冲突 |

### 7. Issue 管理

| 功能 | 状态 | 说明 |
|------|------|------|
| Issue CRUD | ✅ | 创建、查询、更新、关闭、重开 |
| 标签分类 | ✅ | 自定义标签名称 + 颜色 |
| 优先级管理 | ✅ | low / medium / high / critical |
| 指派 | ✅ | 指派给指定用户 |
| 评论 | ✅ | Markdown 评论 |
| 标签筛选 | ✅ | 按标签筛选 Issue |

### 8. Release 管理

| 附件管理 | ✅ | 上传 / 下载 Release 附件 |

### 12. 应用管理

| 功能 | 状态 | 说明 |
|------|------|------|
| 健康检查 | ✅ | `/health` |
| 系统状态查询 | ✅ | 进程、内存、运行时间 |
| 配置管理 | ✅ | 获取 / 更新 / 重置 / 验证配置 |
| 日志查看 | ✅ | 按日期、级别、行数过滤 |

### 15. 系统配置

| 功能 | 状态 | 说明 |

| WAL 模式配置 | ✅ | SQLite WAL 模式细粒度调优 |
