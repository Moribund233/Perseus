# Perseus 用户手册

> **适用于**: Web 前端与桌面端（desktop）用户
> **更新日期**: 2026-09-18

Perseus 是一个基于 Git 的自托管协同开发平台，提供代码托管、Pull Request、Issue、
实时协作编辑、WebHook 通知等服务。本手册按使用角色说明常用操作。

## 1. 快速上手

### 1.1 登录与注册

1. 打开 Perseus 首页（开发环境 http://localhost:5173，生产环境网关地址）。
2. 点击 **登录** -> **注册**，填写用户名 / 邮箱 / 密码，或使用 GitHub / GitLab OAuth。
3. 管理员账号由部署者在环境变量 `PERSEUS_ADMIN_USERNAME / PERSEUS_ADMIN_PASSWORD` 中预设。

### 1.2 首页布局

- 左侧导航：仓库、Pull Request、Issue、我的工作台（Dashboard）、设置。
- 顶部：全局搜索（仓库 / 代码）、语言切换（中 / EN）、个人菜单。
- 工作台聚合：我可访问的仓库、我发起的/指派的 PR 与 Issue、最近动态。

## 2. 仓库（Repository）

### 2.1 创建仓库

1. 顶部 **+ 新建仓库**。
2. 填写名称、可选描述，选择 **公开 / 私有**。
3. 仓库创建后自动初始化对应 Git 仓库，支持自托管 HTTPS 与 SSH 两种克隆方式。

### 2.2 克隆与推送

```bash
# HTTPS（经网关）
git clone http://localhost:8080/{username}/{repo}.git
# SSH（若已配置 SSH 密钥）
git clone ssh://git@localhost:2222/{username}/{repo}.git
```

- 认证：HTTPS 使用 JWT/口令，SSH 使用密钥。
- 在 **设置 -> SSH 公钥** 上传公钥后可免密推送。

### 2.3 分支管理

- 仓库页可查看/切换分支、新建分支、删除分支。
- **保护分支**：管理员可设置默认分支保护，要求代码评审（require_code_review）
  或状态检查通过后才允许合入。

## 3. Pull Request / Issue

### 3.1 发起 Pull Request

1. 在仓库页分支下拉选择源分支，点击 **发起 PR**。
2. 标题 / 描述支持 Markdown 预览；可选指派评审者、关联 Issue。
3. 提交后可评论、合并（需满足分支保护规则）、关闭或重开。

### 3.2 Issue 管理

- 创建 Issue：填写标题、描述、优先级，可指派负责人与打标签。
- 批量操作：多选后批量关闭 / 重开 / 添加标签。
- 状态流转：open / closed / reopened，变更记录同步到活动时间线。

## 4. 代码搜索

- 全局搜索框支持 **代码搜索**（内容来自 Git 对象，索引持久化主库，PostgreSQL pg_trgm 加速子串检索）。
- 支持按仓库 / 语言 / 路径过滤，跨仓库聚合结果。
- PR 合并后搜索索引自动重建，搜索结果即时更新。

## 5. 实时协作（Collaboration）

- 打开任一 Markdown/源码文件，多人可同时编辑（Web：CodeMirror 6；桌面端：Monaco，均基于统一 **Yjs/CRDT** 底座实时同步）。
- 光标/选区与在线成员实时可见，支持**跟随模式**：点选参与者跟随其视口，或发起「跟我来」广播位置。
- 保存语义：显式保存将协作内容提交到 Git，全员广播「Git 已提交 {短 SHA}／会话已同步 · v{N}」双态徽标；断线期间本地编辑保留，重连后由 CRDT 自动收敛合并。
- **邀请链接**：编辑器工具栏「分享协作」生成会话级临时权限链接（仅仓库成员），被邀请人凭链接加入只读/可写受限会话（会话级权限可被发起人随时覆盖或踢出）。
- **自动保存**：会话空闲时自动落盘草稿分支 `collab/draft-{branch}`，不污染工作分支；会话最后一人离开后现场保留一段时间（TTL），窗口内重新加入可恢复。

## 6. 通知

- 实时通知：被 @提及、PR 评审/合入、Issue 评论、发布时即时推送（WebSocket）。
- 顶栏铃铛查看全部通知，未读计数实时更新；支持批量标记已读。
- 设置页可配置站内/邮件通知偏好。

## 7. WebHook

- 仓库 **设置 -> WebHook** 新增回调：填写 URL、选择事件、可设置密钥签名。
- 支持事件：push、tag_push、pull_request.*、issue.*、release.*、repository.* 等。
- 投递含 HMAC-SHA256 签名头（`X-Hub-Signature-256`），具备 3 次指数退避重试，
  投递记录可查（状态码、耗时、响应体）。
- **安全提示**：WebHook 地址禁止指向内网/回环地址（SSRF 防护）。

## 8. 个人设置

| 功能 | 说明 |
|------|------|
| 个人资料 | 用户名、邮箱、全名、头像 |

### 国际化（中 / 英 切换）

- 顶栏或桌面端设置页下拉切换 **中文 / English**，即时生效。
- 全部业务文案与 API 错误消息随语言切换双语返回。
