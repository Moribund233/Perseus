Perseus

构建 passing 版本 v0.4.0 协议 MIT

基于 Git 的本地化协作开发平台 — 代码托管、实时协作、团队聊天与代码审查，尽在一个统一平台。

特性

  • 自托管 Git 仓库托管，分支保护与精细化访问控制
  • 基于 CRDT 的实时协同编辑，断线自动合并
  • 行内 PR 审查、Issue 追踪与团队聊天

快速开始

git clone https://dev.perseus.local/acme/perseus.git
cd perseus && docker compose up -d
