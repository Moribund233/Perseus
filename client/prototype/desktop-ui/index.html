Perseus Desktop — 页面设计原型

桌面端定位为「远程 Perseus 客户端 + 本地工作区」，IDE 优先、协作为辅。 视觉沿用 web 端 GitHub Dark 设计语言（antd token 对齐），交互按桌面习惯深化： 无框窗口、命令面板、活动栏/侧栏/底部面板三段式 IDE 布局、离线优先的状态反馈。 实时能力涵盖 Yjs 协同编辑与团队聊天（WS 透传服务器事件流）。 点击下方卡片进入各界面，原型条可切换页面、模拟离线与 Toast。

01启动台 首次启动 / 工作区入口：最近工作区、服务器、打开本地目录、Clone、快捷键引导 02仓库列表 连接服务器后的浏览视图：服务器切换、全局搜索入口、仓库网格卡片 03仓库详情 · 代码 资源管理器 + 文件树筛选、最新提交条、文件列表、README 渲染、Clone 到工作区 04Issues 列表/详情双栏：状态与优先级筛选、时间线评论、负责人与标签侧栏 05Pull Requests 列表/详情双栏：open/merged/closed 状态色、diff 统计、审查流与合并盒 06IDE 工作区 ★核心 活动栏（Explorer/搜索/Git/PR/Issue/聊天）、Monaco 标签页、LSP Problems、终端、命令面板（Ctrl+K） 07团队聊天 · realtime 频道/私信三栏、代码片段、表情回应、在线成员与输入中指示；离线时消息入队，重连自动补发 08服务器管理 多服务器注册表：健康状态、设为当前、添加/编辑/删除，凭据进系统密钥库 09设置 本地网关信息、外观主题、编辑器偏好、快捷键表、关于与更新
