🏛️ Perseus Core

TypeScript Build Passing v2.4.0

The core engine for the Perseus collaborative development platform. Built with performance and extensibility in mind.

Features

  • Real-time collaborative editing with CRDT support
  • Advanced syntax highlighting for 50+ languages
  • Built-in terminal with SSH tunneling
  • Git integration with visual diff viewer
  • Plugin system for custom extensions

Quick Start

npm install @perseus/core
import { Editor } from '@perseus/core'

const editor = new Editor({
  container: '#app',
  theme: 'perseus-dark',
  language: 'typescript'
})

Documentation

Visit our docs/ directory or check the API Reference for detailed usage guides.

This PR adds WebSocket support to enable real-time collaboration features. Key changes include:

• Implemented CollaborationEngine class with CRDT-based conflict resolution
• Added WebSocket server with automatic reconnection
• Integrated presence awareness (cursors, selections)
• Added operational transform fallback for older clients

The implementation follows the Yjs protocol and is compatible with existing document models. All tests pass and performance benchmarks show <50ms sync latency.
