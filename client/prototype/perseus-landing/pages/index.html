Everything you need

A complete Git platform

From repository hosting to real-time collaborative editing, Perseus packs everything your team needs into one self-hosted solution.

Code Hosting

Full Git repository management with fork, star, and granular access control across four roles: Owner, Admin, Developer, and Readonly.

Pull Requests & Review

Draft PRs, inline code reviews, labels, conflict detection, and activity timelines — everything for a smooth review workflow.

Issue Tracking

Create, close, and reopen issues with priorities, labels, batch operations, and threaded comments for organized project management.

Real-time Collaboration

Google Docs-style collaborative editing powered by Yjs CRDT. Live cursors, presence indicators, and conflict-free merging.

Code Search

Blazing-fast code search across all repositories using Git object indexing and PostgreSQL pg_trgm GIN for substring matching.

Webhooks & CI

18 event types with HMAC-SHA256 signing, delivery history, automatic retries, and build status tracking for CI integration.

Release Management

Tag-based releases with file attachments, draft and pre-release support, and structured release notes for every version.

Admin & Monitoring

Full admin console with system monitoring, configuration management, Redis administration, and real-time log streaming.

Real-time Collaboration

Edit together, in real time.

Perseus brings Google Docs-style collaboration to your codebase. Multiple developers can edit the same file simultaneously with live cursors, presence indicators, and zero merge conflicts.

Live Cursors & Presence

See exactly where your teammates are editing and who is online in each file.

Yjs CRDT Engine

Powered by battle-tested Yjs CRDT algorithm for conflict-free concurrent editing at any scale.

Built-in Chat & Comments

Repository chat channels, direct messages, and inline file comments — all WebSocket real-time.
